# Simple Interest Calculator

A Bash calculator that computes simple interest from the principal amount,
annual interest rate (as a percentage), and time period in years.

## Formula

Simple interest = principal * annual rate * time / 100

## Usage

Run `bash simple-interest.sh` and enter the three requested values.

Example: principal 1000, annual rate 5, and time 2 years gives interest 100.00.
